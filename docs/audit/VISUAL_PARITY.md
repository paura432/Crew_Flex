## Documented exceptions to pixel parity

- Spanish copy is not reproduced (OD C-5); labels are translated 1:1 where the screen exists.
- Google Fonts (Inter + Outfit) are not loaded from a CDN; Inter is self-hosted through `next/font`.
- S1's demo chrome (role select, demo banner, reset) is intentionally not reproduced.
- Day-cell click semantics: S1 toggles a per-day state in local state; the current model stores UTC
  windows. A day click creates/updates/deletes a one-day window; days covered by a longer window are
  shown as covered and edited through the windows panel (no silent splitting of windows).
