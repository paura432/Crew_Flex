# Feature inventory

Sources: S1 = `CrewFlex_v1.1.html`, S2 = Blueprint, BRIEF = current engineering direction. Routes are the
current Next.js app. Status vocabulary: `NOT_FOUND` · `SOURCE_ONLY` · `UI_ONLY` · `MOCKED` · `PARTIAL` ·
`IMPLEMENTED_UNVERIFIED` · `VERIFIED` · `BLOCKED`. "Backend" = Edge Function + tables. "Tests" = existing
automated coverage. Evidence for each row: the S1 function/section named, the repo path, or a test file.

`IMPLEMENTED_UNVERIFIED` below means: implemented and tested locally (Vitest/PGlite/Deno), **not** verified
against the deployed app because Edge Functions are not deployed (`SUPABASE_CURRENT_STATE.md`).
