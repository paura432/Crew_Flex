# Aviation maintenance glossary — ES / EN

Vocabulary used by the Crew Flex interface. Column "Kept as is" lists terms that must stay identical in
both languages (codes, acronyms, regulatory names). Interface concepts are translated as in the table.

## Never translated

| Term                                                    | Why                                                        |
| ------------------------------------------------------- | ---------------------------------------------------------- |
| EASA, Part-66, AESA, UK CAA, FAA                        | Regulators and regulations                                 |
| B1.1, B1.3, B2, CAT-A, CAT-C                            | Part-66 licence categories (catalog codes)                 |
| TR-A320, TR-A330, TR-A350, TR-B737, TR-B787, TR-ATR72   | Type ratings (catalog codes); "Type rating" stays English  |
| A320, A330, A350, B737, B787, ATR 72                    | Aircraft types                                             |
| EWIS, HF, FTS, SMS, NDT, NDT-UT2, BORESCOPE             | Continuation training / approvals / skills (catalog codes) |
| AOG, MRO, OJT, CRS                                      | Industry acronyms                                          |
| Crew Flex, display names, organization names, locations | Product and user data                                      |
| UTC                                                     | Time reference (BR-10)                                     |
