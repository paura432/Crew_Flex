## 2. Availability cycle generator (exact)

Source: `src/features/planning.js` (`cycleStates`, `cycleDay`), used by both `ConnectedCalendar.jsx`
and the demo `AvailabilityPlanner.jsx` (via `business.js` `patternForDate`).

`ROTATIONS = ['7x3','7x4','5x2','7x3/7x4','6x4','5x5','4x4','10x10','15x15','Personalizado','2D2N4OFF','Noche','Partido','Flexible']`

| Pattern (label)                      | Cycle (W = working, O = off), day 1 first | Length |
| ------------------------------------ | ----------------------------------------- | ------ |
| `7x3` (7–3)                          | 7 W, 3 O                                  | 10     |
| `7x4` (7–4)                          | 7 W, 4 O                                  | 11     |
| `5x2` (5–2)                          | 5 W, 2 O (anchored, **not** Mon–Fri)      | 7      |
| `7x3/7x4` (7–3 / 7–4 alterno)        | 7 W, 3 O, 7 W, 4 O                        | 21     |
| `6x4` (6–4)                          | 6 W, 4 O                                  | 10     |
| `5x5` (5–5)                          | 5 W, 5 O                                  | 10     |
| `4x4` (4–4)                          | 4 W, 4 O                                  | 8      |
| `10x10` (10–10)                      | 10 W, 10 O                                | 20     |
| `15x15` (15–15)                      | 15 W, 15 O                                | 30     |
| `Personalizado` (Otro · ciclo libre) | user array, 1–31 entries, each W or O     | 1–31   |
| `2D2N4OFF`                           | 4 W, 4 O (day/night distinction lost)     | 8      |
| `Noche`                              | 5 W, 2 O                                  | 7      |
| `Partido`                            | 5 W, 2 O                                  | 7      |
| `Flexible`                           | 1 O (every day rest)                      | 1      |

Rules in code:

- Generic patterns match `^(\d+)x(\d+)(?:\/(\d+)x(\d+))?$`; each block is an integer 1–31 and the
  **sum ≤ 31**, otherwise "El ciclo debe caber en 31 días". Blocks alternate W, O, W, O. The server
  (`availabilityUpdate`) validates any string that matches the regex, not only the 14 listed.
- `cycleDay(pattern, anchor, date)`: dates must be valid `YYYY-MM-DD`, parsed at `T12:00:00Z`;
  `offset = round((date − anchor) / 86 400 000)`; state = `cycle[((offset % len) + len) % len]`, so
  dates before the anchor work too. Whole UTC days only; no hours, no fatigue limits.
- Generation (`ConnectedCalendar.generate`): visible month only; skip `d < today (UTC)`, assigned days,
  and — unless "Reemplazar" — days already pending or saved in `schedule`. `O` becomes `available` when
  "Publicar descansos generados como disponibles" is ticked; otherwise W/O stay **private** (only
  `available` and `aog` create published intervals). Default pattern `7x3`; default custom cycle 14 × O
  (demo: 4x4 and 7 W + 7 O).
- Current mapping (`rotation.ts`): W → `unavailable` window, O → nothing (or `available` when
  publishing rest), `aog` not mappable until C-8 / D-05.

## 3. Tools hub — `src/tools/engine.js` 1.0.0 (unchanged since V1.3)

Number input (`number`): trimmed; comma **or** dot decimal, both together rejected ("no separadores de
miles"); fractions `a/b` and mixed `a b/c` (denominator ≠ 0); scientific notation allowed; |x| ≤ 1e15;
non-negative unless the magnitude is signed (pressure, temperature, ΔT, angle). No intermediate rounding;
display `Intl.NumberFormat('es-ES')`, ≤ 6 decimals.

Conversion: `canonical = value × factor + offset`; `result = (canonical − offset_to) / factor_to`.
